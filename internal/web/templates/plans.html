Plans

A plan sets how often a source is re-listed via the API (discovery) and how often each repo is checked via git ls-remote, which costs no API quota. With adaptive on, each check that finds a change halves the repo's interval and each quiet check stretches it by 1.5×, within min and max. A repo in several sources follows the strongest plan. Durations: 30m 6h 2d 1w. Saved to gitbackup.yaml.
