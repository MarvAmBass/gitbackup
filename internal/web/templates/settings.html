Forge instances

One entry per server, created automatically when you add a source. Tokens are optional but raise the limits (GitHub 60 → 5000/h); sourcehut needs one for its API, GitLab snippets need the owner's token. A token can be written as ${ENV_VAR} to read it from the environment. The scheduler never spends the reserve; only buttons you press may.

Hooks

Run a shell command when something happens – send a message, trigger another backup, anything. Events: event kinds (rewritten, gone, asset-replaced, release-new, …), history for everything where upstream removed or rewrote something, or *. The command gets GB_EVENT, GB_REPO, GB_PATH, GB_REF, GB_VERSION, GB_DETAIL, … and the event as JSON on stdin.

HTTPS

Port: empty = the same port serves HTTP and HTTPS (TLS is recognised per connection); or a separate port like :8443 – then also publish it in docker-compose. Let's Encrypt needs the domains to point here and the service reachable from the internet on port 443 (or 80) – e.g. via port forwarding. Applied live; if a certificate can't be loaded, plain HTTP keeps working.
